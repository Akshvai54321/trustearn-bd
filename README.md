# TrustEarn BD — Free starter demo

## কী আছে
- মোবাইল-উপযোগী বাংলা ড্যাশবোর্ড
- ডেমো পয়েন্ট, রেফারেল, ভিডিও/টাস্ক এবং উত্তোলন আবেদন UI
- কোনো বাস্তব টাকা, বিজ্ঞাপন, অ্যাকাউন্ট বা পেমেন্ট প্রসেসিং নেই

## ফ্রি GitHub Pages-এ প্রকাশ
1. GitHub-এ সাইন আপ/লগইন করুন।
2. New repository তৈরি করুন, নাম দিন `trustearn-bd`।
3. `index.html` ফাইলটি আপলোড করে Commit করুন।
4. Repository → Settings → Pages → Deploy from a branch নির্বাচন করুন।
5. Branch `main`, folder `/root` নির্বাচন করে Save করুন।
6. কিছুক্ষণ পর GitHub Pages-এর দেওয়া URL-এ সাইট দেখা যাবে।

## বাস্তব ইনকাম চালুর আগে
এই ডেমোকে সরাসরি বাস্তব ইনকাম সাইট হিসেবে ব্যবহার করবেন না। বাস্তব সদস্য/রেফারেল/পয়েন্ট/উত্তোলনের জন্য:
- নিরাপদ backend ও database (যেমন Supabase) এবং server-side validation
- স্পনসর/বিজ্ঞাপনদাতার লিখিত অনুমতি ও বৈধ earning source
- প্রতারণা ও একাধিক অ্যাকাউন্ট ঠেকানোর ব্যবস্থা
- গোপনীয়তা নীতি, শর্তাবলি, ন্যূনতম উত্তোলন ও স্পষ্ট earning rules
- অনুমোদিত পেমেন্ট প্রদানকারীর merchant/business onboarding
প্রয়োজন। বিজ্ঞাপনে কৃত্রিম ক্লিক/ভিউ করানো যাবে না; বিজ্ঞাপন নেটওয়ার্কের নীতি মেনে চলতে হবে।
